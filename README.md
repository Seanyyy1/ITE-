Purpose
This repository was created to practice the basic GitHub collaboration workflow: adding files, working on a separate branch, opening a pull request, getting it reviewed by a collaborator, and merging the changes into the main branch.

Collaborators

Sean Griffith (@Seanyyy1), repository owner and author
Kofi Hossannah (@kofi20i), collaborator and pull request reviewer

Steps Followed

1. Created a new GitHub repository named ITE-.
2. Uploaded Name.py, a Python script that prints my first and last name, to the main branch.
3. Added kofi20i as a collaborator through Settings → Collaborators, and they accepted the invitation.
4. Created a new branch called tutorial-branch.
5. Added a new file, sample.py, on tutorial-branch.
6. Committed the file with the message "Added sample file for tutorial".
7. Pushed the new branch to GitHub (commits made on github.com are saved to GitHub directly).
8. Opened a pull request from tutorial-branch into main and assigned kofi20i as the reviewer.
9. The collaborator reviewed and approved the pull request.
10. Merged tutorial-branch into main.
11. Added this README.md file to document the project.
